# SpendWise

A personal finance workspace for tracking spending, budgets, goals, accounts, and subscriptions.

## GitHub Pages

Pushing changes to `main` builds the Vite client and deploys it to:

https://muvvabhanusanjay-blip.github.io/spread-expenceses/

Client routes use the URL hash so refreshing a page works on GitHub Pages.

GitHub Pages hosts only the static client. The Express/MongoDB API in `server/` must be deployed separately for login and data features to work.
